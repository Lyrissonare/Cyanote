# 🌊 Cyanote

一个前后端完备（前后分离）的博客系统。阅读体验参照 **Hexo / Butterfly**，写作体验参照 **语雀**，全局特征色为**蓝色**，支持**暗色 / 亮色**主题一键切换，列表侧边栏可开启「**未来主义**」先锋风格。

## 功能一览

### 公开前端（`/`）
- **首页**：Hero（标题 + 入口）+ 最新文章 + 探索卡片；侧边栏为 Butterfly 式组件
- **侧边栏**（首页 / 文章页 / 详情页共用）：
  - **未来视效**开关 —— 霓虹、玻璃拟态、动态网格背景的先锋风格（持久化）
  - **站点统计** —— 文章 / 分类 / 标签 / 年份计数卡片
  - 分类列表、加权标签云、归档
- **最新文章（数量后台可调）**：完整展示 N 篇（默认 3，管理台 ⚙ 设置 1-10），其后渲染第 N+1 篇的「幽灵卡片」—— 上半篇可见，下半篇浸入呼吸蓝光晕，光晕中央的「查看全部文章」按钮一键进入文章列表
- **跟随鼠标的光照**：柔和的蓝光晕随光标移动（惰性缓动，触屏设备自动隐藏）
- **关于页**：导航「关于」，内容为管理台站点设置中的 Markdown，保存即时生效
- **文章列表**：分页、全文搜索、按分类 / 标签过滤
- **文章详情**：渲染正文、目录 TOC 滚动高亮（点击平滑滚动定位，不触发路由跳转；目录与侧边栏合并为单一粘性列，滚动互不遮挡）、分类标签、阅读计数、封面
- **分类 / 标签 / 归档**：分组列表、加权标签云、按年-月时间轴归档
- **主题**：暗色 / 亮色切换（跟随系统默认，持久化）
- **亮色模式 × 未来视效冲突提示**：开启未来视效而处于亮色时，侧边栏出现“⚠️ 亮色模式与未来视效冲突”提示（仅此一处，页面底部无重复提示），并提供“切换暗色”一键修复

### 管理台（隐藏入口 `/admin`，公开站点无任何入口链接）
- 独立前端入口（`/admin/index.html`，`<meta name="robots" content="noindex">`），公开页面与打包代码中不包含任何写作入口与令牌逻辑；管理台资源一律 `no-cache` 下发，不会因缓存停留在旧版本
- 写操作仍需管理令牌：`Authorization: Bearer <token>`（默认 `cyanote-demo-token`，可用环境变量 `CYANOTE_TOKEN` 覆盖，服务端使用恒定时间比较）
- **五大管理视图**（顶部标签页导航）：
  - **📄 文章管理**（默认）：全部文章列表（标题/slug/状态/日期/阅读数），标题搜索、全部/已发布/草稿筛选，行内一键 **编辑 / 发布 / 撤回 / 删除**
  - **✏️ 写文章**：语雀式 Markdown 编辑器（见下）
  - **🗂️ 分类管理**：列出全部分类与文章数，行内**重命名 / 删除**，实时同步所有文章
  - **🏷️ 标签管理**：同上，管理所有标签
  - **⚙️ 站点设置**：首页「最新文章」展示数量（1-10）、关于页内容（Markdown），保存即生效
- **语雀式 Markdown 编辑器**：
  - 编辑 / 双栏 / 预览三视图切换 + 250ms 防抖实时渲染
  - **快捷工具栏**：加粗、斜体、下划线、删除线 ｜ 标题、引用、无序/有序/任务列表 ｜ 行内代码、代码块、链接、图片上传、表格 ｜ 撤销、重做（自维护历史栈）
  - 图片**拖拽 / 粘贴 / 工具栏选择** → 实时上传 → 光标处插入并立即渲染
  - 标题、slug（自动从标题生成）、摘要、封面、分类 / 标签 chips、草稿 / 发布 / 删除、`Ctrl/Cmd+S` 保存、本地自动暂存

### 后端 API（Node.js + Express + 内置 `node:sqlite`）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/meta` | 站点统计、分类 / 标签计数、归档 |
| GET | `/api/archive` | 归档文章列表 |
| GET | `/api/settings` | 站点设置（首页文章数量、关于页内容） |
| PUT | `/api/settings` | 更新站点设置 ⚠️需令牌 |
| PUT | `/api/categories/:from` | 重命名分类（同步所有文章）⚠️需令牌 |
| DELETE | `/api/categories/:name` | 删除分类（从所有文章移除）⚠️需令牌 |
| PUT | `/api/tags/:from` | 重命名标签（同步所有文章）⚠️需令牌 |
| DELETE | `/api/tags/:name` | 删除标签（从所有文章移除）⚠️需令牌 |
| GET | `/api/articles` | 列表（`status/category/tag/q/page/pageSize/order`） |
| GET | `/api/articles/:slug` | 单篇详情（令牌可读草稿，公开访问自动 +1 阅读） |
| POST | `/api/articles` | 新建文章 ⚠️需令牌 |
| PUT | `/api/articles/:slug` | 更新文章 ⚠️需令牌 |
| DELETE | `/api/articles/:slug` | 删除文章 ⚠️需令牌 |
| POST | `/api/articles/:slug/publish` | 发布 ⚠️需令牌 |
| POST | `/api/articles/:slug/unpublish` | 撤回草稿 ⚠️需令牌 |
| POST | `/api/uploads` | 图片上传（PNG/JPEG/GIF/WebP/AVIF，≤20MB）⚠️需令牌 |
| GET | `/api/auth/check` | 校验管理令牌 |

## 快速开始

```bash
npm install        # 安装依赖
npm run seed       # 写入演示文章（含 1 篇草稿）
npm start          # 启动 http://localhost:3810
```

- 公开站点：`http://localhost:3810`
- 管理台（隐藏入口）：`http://localhost:3810/admin/`（默认令牌 `cyanote-demo-token`）

## 目录结构

```
server/            # 后端：Express 应用、路由、SQLite 存储、种子数据
public/            # 公开前端（零构建原生 JS SPA，无任何管理与令牌代码）
  css/             # app.css（设计系统）future.css（未来主义）
  js/              # api(只读)/theme/markdown/site + pages/*
admin/             # 管理台前端（独立入口，隐藏在 /admin，不对外链接）
  css/admin.css    # 管理台外框 + Markdown 工具栏
  js/              # editor.js（编辑器+工具栏）api.js（令牌客户端）main.js
data/              # 运行时生成：cyanote.db + uploads/（已 gitignore）
```

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `3810` | 服务端口 |
| `CYANOTE_TOKEN` | `cyanote-demo-token` | 管理令牌（生产务必修改） |
